# CommandGuard

CommandGuard is a SwiftUI app that builds and signs simulated industrial control commands, then sends them to a mocked gateway for validation. The UI focuses on a datacenter cooling use case (temperature, humidity, fan speed, valve position), while the data layer demonstrates canonicalized JSON signing with ECDSA P-256.

## Features

- Command builder UI with sliders and toggles for cooling system setpoints.
- Signed command envelopes using ECDSA P-256 (CryptoKit) and canonical JSON.
- Simulated gateway send path with latency, safety checks, and network error injection.
- Recent command timeline with success/failure status and summaries.

## How it works

1. The UI gathers setpoints and flags into a `CommandBody`.
2. A `CommandEnvelope` is created with timestamp, operator ID, request ID, and nonce.
3. The envelope is canonicalized (sorted JSON keys, signature removed) and signed.
4. The signed envelope is logged, and the `CommandSendService` simulates gateway behavior.

## Project structure (key files)

- `CommandGuard/CommandGuard/CommandGuardApp.swift` — App entry point and SwiftData container setup.
- `CommandGuard/CommandGuard/HomeView.swift` — Main UI for building and sending commands.
- `CommandGuard/CommandGuard/HomeViewModel.swift` — State management and send flow orchestration.
- `CommandGuard/CommandGuard/CommandModels.swift` — Command body, envelope, signature models, and helpers.
- `CommandGuard/CommandGuard/CryptoSigner.swift` — Keychain-backed ECDSA P-256 signer.
- `CommandGuard/CommandGuard/CommandSendService.swift` — Simulated gateway send/response logic.
- `CommandGuard/CommandGuard/RecentCommandsView.swift` — Recent command history UI.
- `CommandGuard/CommandGuard/SendStatus.swift` — Send state and status styling helpers.
- `CommandGuard/CommandGuard/Item.swift` — Default SwiftData model from the Xcode template.

## Running the app

1. Open the project in Xcode.
2. Select an iOS Simulator or device.
3. Build and run.

## Notes

- `operatorId` and `nextRequestId` are persisted via `@AppStorage` in `HomeView`.
- The signed envelope is printed to the console for inspection.
- The gateway logic is simulated; there is no real network transport.
